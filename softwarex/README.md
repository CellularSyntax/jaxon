# jaxon — SoftwareX companion paper

Original Software Publication for SoftwareX, accompanying the main
(Journal of Neural Engineering) manuscript. Built on the same
Elsevier `elsarticle` / SoftwareX template used for the golgi
SoftwareX submission.

## Files
- `jaxon_softwarex.tex` — manuscript source (elsarticle, `\journal{SoftwareX}`)
- `jaxon_softwarex.pdf` — compiled preview (tectonic; elsarticle bundled)
- `figures/jaxon_architecture.png` — Fig 1, software architecture
- `figures/jaxon_validation.png`   — Fig 2, validation + scaling (reused from main paper Fig 1)
- `figures/jaxon_selectivity.png`  — Fig 3, differentiable selectivity example (main paper Fig 3)

## Structure (SoftwareX OSP template)
Code metadata table (C1–C8) · Motivation and significance · Software
description (architecture, functionalities, sample code) · Illustrative
examples · Impact · Conclusions · Data availability & licensing · CRediT ·
bibliography · executable-software metadata table (S1–S7).
